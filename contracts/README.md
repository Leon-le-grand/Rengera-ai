# API contracts

`openapi/v1.json` is the versioned HTTP contract for the V2 server. It is
generated from the FastAPI application, never hand-edited.

## Generate

```bash
cd server
uv run python -m scripts.export_openapi
```

## Check for drift

```bash
cd server
uv run python -m scripts.export_openapi --check
uv run pytest -q tests/test_openapi.py
```

The contract tests validate the document against the OpenAPI 3.1 specification,
reject duplicate operation IDs, assert deterministic rendering and require the
checked-in artifact to match the application. CI and review must run these
before accepting a server change.

## Generate clients

The TypeScript client is generated from this contract with
`@hey-api/openapi-ts`, pinned to `0.99.0` in `platform/package.json`:

```bash
cd platform
pnpm generate:api
```

The generated output lives in `platform/src/api/generated/` and is checked in;
do not hand-edit it. A Dart client generated by OpenAPI Generator is still
pending a pinned generator configuration and a compilation check. Until then,
mobile work must not assume generated Dart types exist.

## Policy

- The FastAPI app is the source of truth for paths, schemas and operation IDs.
- Every operation must have a stable, unique `operationId`.
- Additions are backwards compatible within `v1`. Removing or renaming a field,
  changing its type, tightening validation or changing an error code requires a
  versioned replacement or an agreed migration window. The contract test's exact
  path/operation list fails on accidental removal or rename, and review must
  check field-level compatibility for every schema change.
- Generated clients are checked in separately and must be regenerated from this
  file. Never hand-edit generated client output.
- Error responses use the shared `ErrorResponse` envelope with a stable code,
  safe message and correlation request ID.
- The contract describes only implemented endpoints. Planned groups are added
  when their slice lands, so clients never see fake operations.
- Legal source, version and review fields are part of the public contract; do
  not replace an unknown status or language with an optimistic default.
