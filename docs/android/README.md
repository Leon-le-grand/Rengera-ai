# Android build guide moved

The former Capacitor Android wrapper under `web/android/` has been removed from the current worktree. The canonical Android application is the Flutter project under [`mobile/`](../../mobile/).

Use [`mobile/README.md`](../../mobile/README.md) for local setup and [`docs/mobile/ARCHITECTURE.md`](../mobile/ARCHITECTURE.md) for implementation status. The old instructions on this page described a separate Capacitor app and are superseded; do not follow them to create another Android project.
